# Huihui Qwen3.8 round trips on A100 40GB — 2026-10-03

Both models completed model discovery, nonstreaming inference, three streamed samples, metrics persistence,
and confirmed shutdown through colabinet. Median generation was **46.50 tokens/s for 27B** and
**19.65 tokens/s for Flash-Next**. [Sample measurements and provenance](2026-10-03-huihui-a10040.json)
contain metrics only, with no prompt or response bodies.

## Configuration and results

The successful run used one NVIDIA A100-SXM4-40GB (40,960 MiB), 89.6 GB host RAM, 12 logical CPUs
(Intel Xeon at 2.20 GHz), driver 580.82.07 and the existing CUDA 13.0 Torch installation.
Both models used llama.cpp **b11273**, context **8192**, **f16** KV, one slot, temperature 0, seed 42,
and `reasoning_effort: "none"`. Requests went through the metering proxy and private SSH tunnel.

On the successful VM, 27B installation took 15.5 s, download 949.7 s for 17.74 GB including vision,
and load 111.1 s. Flash-Next reused the installed engine and loaded in 267.1 s.
Its shards were prefetched concurrently with 27B setup; the recorded **44.6 s download phase is only the
remaining wait during reconfiguration**, not the time to transfer the entire 111.33 GB. The same VM served
27B first, then Flash-Next. These timings are not a controlled cold-start comparison.

## Changes needed for the round trip

The existing 27B preset already covered the requested model. The new Flash-Next preset uses 8K/f16 and
labels CPU offload. Split GGUF setup now fetches every shard concurrently, checks completeness, resumes
missing companions even when the first shard is cached, and records their aggregate size. Hub size estimates
also sum all shards; weights exceeding VRAM now report CPU offload even when hybrid KV size is unknown.

The first A100 attempt passed arithmetic and one 128-token stream at 46.45 tok/s, then the next request
returned 502 `RemoteProtocolError`. A local reproduction produced the same failure when reusing a connection
whose closure became visible only on the next read. The supervisor now opens fresh upstream connections
and does not retry inference POSTs. The regression failed with 200/502 before the change and passed with
200/200 afterward. All subsequent live requests passed. The original closure's origin is unproven.

This verifies short text prompts at one slot and 128 output tokens. Long context, concurrency, reasoning
